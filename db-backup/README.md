# نسخة قاعدة البيانات (مشفّرة)

نسخة من قاعدتي بيانات خادم التطوير، مأخوذة يوم 2026-11-23، ومرفوعة مع الكود بطلب صاحب النظام.

## لماذا هي مشفّرة

القاعدة فيها بصمات كلمات مرور الحسابات، وأسماء وبريد وتليفونات أعضاء هياكل الكليات، وسجل التدقيق. قاعدة المشروع ([ADR-0009](../docs/adr/0009-no-backups-in-git.md)) أن النسخ الاحتياطية لا تدخل git، فهذه النسخة استثناء بشرطين: أنها مشفّرة، وأن كلمة المرور ليست في المستودع.

- **التشفير:** AES-256 بأداة `openssl` (مفتاح مشتق بـ PBKDF2، 600,000 دورة).
- **كلمة المرور:** عند صاحب النظام خارج المستودع. دونها لا تُقرأ النسخة.

## المحتوى بعد فك التشفير

| الملف | ما هو |
|---|---|
| `tier1.dump` | قاعدة PostgreSQL كاملة (`pg_dump` بالصيغة المخصصة). |
| `tier1_logs.archive.gz` | قاعدة MongoDB `tier1_logs`: سجل التدقيق والسجلات الفنية. |
| `README.md` | خطوات الاسترجاع. |

- **نسخة الكود المطابقة:** الإيداع `7346624`.
- **آخر ترحيل في القاعدة:** `20261123072114_EncryptNationalId`.
- **ليس فيها:** مفاتيح حماية البيانات (`/data/keys`) ولا ملفات الأدلة (`/data/files`).

## فك التشفير

```bash
openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in tier1-db-2026-11-23.tar.enc -out tier1-db.tar
tar -xf tier1-db.tar
```

يسأل الأمر الأول عن كلمة المرور. بعدها اتبع خطوات الاسترجاع في `README.md` المستخرج.
